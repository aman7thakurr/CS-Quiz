- English
- -0.25 for wrong answers
- No interview

  syllabus to the prescribed educational qualification/professional course.
- Accordingly, papers below are evidence for the likely technical MCQ universe, not a claim that
  every topic is guaranteed.

============================================================
SUBJECT → WHICH PAPERS TO USE
============================================================

C PROGRAMMING
Primary: [02], [03], [04], [06], [07], [08], [10], [14], [16]
What to extract:
variables, types, operators, precedence, functions, arrays, strings, pointers, structures,
dynamic memory, recursion, storage classes, scope/lifetime, output tracing.

DATA STRUCTURES
Primary: [03], [06], [07], [08], [10], [14], [16], [18]
Extract:
arrays, linked lists, stacks, queues, trees, BST, heaps, hashing, graphs, BFS/DFS,
traversals, operations and complexity.

ALGORITHMS / COMPLEXITY
Primary: [03], [06], [07], [12], [14], [18]
Extract:
Big-O, searching, sorting, recursion, divide-and-conquer, greedy, dynamic programming basics,
graph algorithms and algorithm tracing.

DBMS / SQL
Primary: [02], [05], [06], [07], [08], [09], [10], [11], [12]
This is one of the strongest recurring areas.
Extract:
keys, ER model, functional dependencies, normalization, relational algebra, SQL, joins,
GROUP BY/HAVING, subqueries, transactions, ACID, concurrency, locks, indexes, recovery.

OPERATING SYSTEMS
Primary: [02], [03], [05], [06], [07], [08], [10], [12]
Extract:
process/thread, scheduling, synchronization, semaphores, deadlocks, memory management,
paging/segmentation, virtual memory, file systems, system calls, Linux basics.

COMPUTER NETWORKS
Primary: [02], [06], [07], [08], [10], [18], [20]
Extract:
OSI/TCP-IP, TCP/UDP, IP, subnetting, DNS, DHCP, ARP, HTTP/HTTPS, FTP, SMTP,
ports, routing/switching, network devices, congestion/security basics.

C++ / OOP
Primary: [02], [03], [06], [07], [08], [10], [18]
Extract:
class/object, encapsulation, abstraction, inheritance, polymorphism, constructors,
destructors, overloading/overriding, virtual functions, exceptions.

JAVA
Primary: [02], [06], [07], [08], [10]
Extract:
classes, inheritance, interfaces/abstract classes, exceptions, runtime basics,
language behavior. No advanced frameworks.

COMPUTER ARCHITECTURE / ORGANIZATION
Primary: [03], [04], [05], [07], [10]
Extract:
CPU, registers, ALU, instruction cycle, memory hierarchy, cache, addressing modes,
I/O, interrupts, binary/hex/number representation.

DIGITAL LOGIC
Primary: [04], [03], [05]
This deserves more attention than it did in my earlier list because the HPPSC Programmer and
Assistant Computer Programmer papers show very concrete digital-logic/number-system MCQs.
Extract:
Boolean algebra, gates, K-map/switching expressions, counters, flip-flops, complements,
number systems, basic combinational/sequential logic.

SOFTWARE ENGINEERING
Primary: [07], [08], [10], [18]
Extract:
SDLC, requirements, design, testing, maintenance, coupling/cohesion, software quality.

SYSTEM ANALYSIS / DESIGN
Primary: [01], [07], [08], [18]
Extract:
requirements, feasibility, DFD, flowcharts, data dictionary, modularity, implementation,
maintenance, system life cycle.

LINUX / TROUBLESHOOTING
Primary: [02], [05], [07], [10]
Extract:
files, permissions, processes, users/groups, commands, packages, networking commands,
basic troubleshooting.

WEB / PHP / INTERNET
Primary: [02], [17], [20], [26]
Extract:
HTTP, client/server, HTML/CSS/JS basics, sessions/cookies, server-side concepts,
basic PHP, web-security fundamentals.

DISCRETE MATHEMATICS FOR CS
Primary: [04], [06], [07], [18]
Extract:
logic, sets, relations, functions, partial orders, graphs, basic counting.

SECURITY
Primary: [02], [07], [10], [20]
Extract:
authentication/authorization, hashing, encryption, digital signatures, malware,
TLS/HTTPS, access control.

============================================================
THE HIGH-VALUE CORE
============================================================

For the one PGIMER vacancy, the study order should remain:

S:
1. C programming
2. Data Structures
3. Algorithms + Complexity
4. DBMS + SQL
5. Operating Systems
6. Computer Networks

A:
7. C++ / OOP
8. Java
9. Computer Architecture / Organization
10. Digital Logic
11. Software Engineering
12. System Analysis / Design

B:
13. Linux / Troubleshooting
14. Web / PHP / Internet
15. Discrete Mathematics
16. Security

I am deliberately NOT treating General English, generic GK/current affairs, typing, office
software trivia, banking-computer-awareness questions, or unrelated maths as core PGIMER
technical preparation.
