## Evidence rules for agents
1. Never claim the PGIMER syllabus is chapter-wise when it is not.
2. Use actual Programmer-family papers to infer recurring MCQ patterns and depth.
3. Use authoritative technical references to validate explanations and original questions.
4. Keep source URL and provenance on every active question.
5. Prefer original concept-equivalent MCQs over copied PYQ wording.
6. Exclude state GK, general English, typing, banking awareness, office trivia and unrelated aptitude.
7. Do not elevate Python simply because an older generic repository used it as a subject.
